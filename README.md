# homebrew-doit (DEPRECATED)

This Homebrew tap is deprecated and no longer maintained. The project has been renamed to **MF DOIT**.

## New Tap Installation
Please use the new tap name to install or upgrade:

```bash
# Untap the old repository
brew uninstall mfdoit
brew untap wreckingadm/doit

# Tap the new repository and install
brew tap wreckingadm/mfdoit
brew install mfdoit
```

For more details, visit the main repository: [wreckingadm/mfdoit](https://github.com/wreckingadm/mfdoit).
